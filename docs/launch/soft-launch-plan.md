# Soft Launch Plan

## Locality

Initial launch is limited to Hyderabad, India, with provider onboarding restricted to a controlled pilot group.

## Entry Criteria

- Sprints 0-9 verification green or explicitly signed off.
- Demo mode disabled in release candidates.
- Razorpay sandbox proof captured, then production payment smoke approved.
- Expo/FCM push token registration and reminder delivery proof captured.
- Support/dispute workflow staffed for launch hours.

## Pilot Controls

- Limit provider approvals to pilot merchants, vets, groomers, and captains.
- Monitor discovery, checkout, appointments, billing, payouts, refunds, and notification errors daily.
- Pause new provider approvals if payment, dispatch, appointment, billing, or support error rates exceed launch thresholds.

## Exit Criteria

- Seven launch days with no unresolved severity-1 incidents.
- Payout reconciliation completed for first batch.
- Support cases resolved within launch SLA.
